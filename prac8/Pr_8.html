Transfer Learning with MobileNet

Retrain a pre-trained MobileNetV2 for custom image categories — e.g. classifying fruits — using frozen feature extraction + a new classification head.

What is Transfer Learning?

Instead of training a neural network from random weights, you start from a model already trained on a massive dataset (ImageNet, 1.2M images, 1000 classes). The early layers have already learned universal visual features — edges, textures, shapes. You only need to teach the final layers your specific task.

Pipeline Overview

1
Load MobileNetV2 (no top)
Download pre-trained weights from ImageNet. Exclude the final Dense(1000) classification layer using include_top=False.
2
Freeze base layers
Set base_model.trainable = False. All 154 layers keep their learned weights — no gradients flow through them.
3
Add custom classification head
GlobalAveragePooling2D → Dense(128, relu) → Dropout(0.3) → Dense(N, softmax). Only these layers train initially.
4
Train Phase 1 — head only
Train for ~10 epochs with learning rate 1e-3. Quick convergence since only a few thousand parameters update.
5
Fine-tune Phase 2 (optional)
Unfreeze top layers of MobileNet (e.g. last 30), reduce learning rate to 1e-5 and train further. Adapts high-level features to your domain.

Step 1: Load & freeze base model

import tensorflow as tf from tensorflow.keras import layers, Model # Load MobileNetV2 without top classification layer base_model = tf.keras.applications.MobileNetV2( input_shape=(224, 224, 3), include_top=False, weights='imagenet' ) # Freeze all base layers base_model.trainable = False print(f"Trainable layers: {len(base_model.trainable_variables)}") # → 0

Step 2: Build the custom head

NUM_CLASSES = 5 # apple, banana, grape, mango, orange inputs = tf.keras.Input(shape=(224, 224, 3)) x = base_model(inputs, training=False) # frozen: always inference mode x = layers.GlobalAveragePooling2D()(x) x = layers.Dense(128, activation='relu')(x) x = layers.Dropout(0.3)(x) outputs = layers.Dense(NUM_CLASSES, activation='softmax')(x) model = Model(inputs, outputs)

Step 3: Data preprocessing

# MobileNetV2 expects pixels in [-1, 1] preprocess = tf.keras.applications.mobilenet_v2.preprocess_input train_ds = tf.keras.utils.image_dataset_from_directory( 'fruits/train', image_size=(224, 224), batch_size=32 ).map(lambda x, y: (preprocess(x), y)) # Data augmentation (avoids overfitting on small datasets) augment = tf.keras.Sequential([ layers.RandomFlip('horizontal'), layers.RandomRotation(0.15), layers.RandomZoom(0.1), ])

Step 4: Phase 1 — train head only

model.compile( optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss='sparse_categorical_crossentropy', metrics=['accuracy'] ) history1 = model.fit(train_ds, validation_data=val_ds, epochs=10)

Step 5: Phase 2 — fine-tune top layers

# Unfreeze top 30 layers of MobileNet base_model.trainable = True for layer in base_model.layers[:-30]: layer.trainable = False # Very small learning rate to avoid catastrophic forgetting model.compile( optimizer=tf.keras.optimizers.Adam(learning_rate=1e-5), loss='sparse_categorical_crossentropy', metrics=['accuracy'] ) history2 = model.fit(train_ds, validation_data=val_ds, epochs=10) model.save('fruit_classifier.keras')
